# FieldShift AI Data Directory

This directory stores static reference datasets, agricultural knowledge bases, crop taxonomy schemas, and NASA dataset manifests for **FieldShift AI** (NASA Space Apps 2026 — *Field Shift: Adapting Farms with NASA Data*).

## Planned Collections
- Crop climate tolerance and water-requirement catalogs
- Soil texture and agronomic adaptation guidelines
- NASA Earth observation dataset mappings (`POWER`, `SMAP`, `MODIS`, `GPM`, `LANDSAT`)
